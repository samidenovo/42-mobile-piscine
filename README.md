# 42 Mobile Piscine

## Description

This repository contains Flutter projects developed as part of the **42 Mobile Piscine** at **42 Berlin**.

The Mobile Piscine introduces mobile application development through small progressive modules. The projects in this repository focus on Flutter, Dart, UI construction, state management, navigation, API usage, geolocation, data display, and mobile app design.

The inspected repository contains projects from:

- `mobileModule00`
- `mobileModule01`
- `mobileModule02`
- `mobileModule03`

No `mobileModule04` or `mobileModule05` implementation was found in the current repository files.

## How to Run From This Clean Version

To run one of the apps from this repository, create a new Flutter project and copy the files from the selected exercise into it.

Example for `advanced_weather_app`:

~~~sh
flutter create advanced_weather_app
cd advanced_weather_app
~~~

Then replace or copy the files from this repository:

~~~text
lib/main.dart
pubspec.yaml
pubspec.lock
assets/
~~~

Install dependencies:

~~~sh
flutter pub get
~~~

Run the app:

~~~sh
flutter run
~~~

For simpler apps without assets, copy only:

~~~text
lib/main.dart
pubspec.yaml
pubspec.lock
~~~

For apps that use geolocation, make sure the target platform has location permissions configured.

The weather apps require an internet connection because they use the Open-Meteo API.
